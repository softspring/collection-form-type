# Contributing

Use the standard package commands before sending changes:

```bash
composer fix
composer test
composer test-bc
composer build-assets
```

`composer test` and `composer test-bc` validate the Composer package and workflow files.

If you change the JavaScript source, rebuild `assets/dist` before sending changes.

[Report issues](https://github.com/softspring/collection-form-type/issues) and [send Pull Requests](https://github.com/softspring/collection-form-type/pulls)
